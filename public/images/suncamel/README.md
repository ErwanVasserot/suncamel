# SunCamel image drop zone

Deposit all local images for the site under this tree:

- `shared/`
- `home/`
- `faq/`
- `contact/`
- `products/`

The application is already configured to use these local files automatically when they exist in `public/`.
If a file is missing, it falls back to the current remote Booqable image.
